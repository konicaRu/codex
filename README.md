# Offline Meeting Minutes Generator

This project provides a Windows-friendly, fully offline tool that splits meeting videos into "slides", extracts screen text and speech, summarises each segment with a local LLM (via LM Studio), and exports the result into PDF or PPTX reports.

## Features

- Scene detection using HSV histograms and SSIM with best frame selection by Laplacian variance.
- OCR through Tesseract (rus+eng) and offline speech-to-text with `faster-whisper`.
- Summaries, topic clustering, and action items generated by a local LM Studio deployment.
- Automatic rendering into PDF (ReportLab) or PPTX (python-pptx) reports with an aggregate summary slide.
- Simple CLI that works offline on Windows 10/11 with Python 3.10+.

## Installation

Install Python dependencies (offline wheels if required):

```bash
pip install -r requirements.txt
```

System prerequisites:

- `ffmpeg` available in `PATH`.
- Tesseract OCR with Russian and English language packs.
- LM Studio running locally (`http://localhost:1234/v1`).

## Usage

```bash
python -m app.cli --input path/to/video_or_folder --format pdf --lang ru+en
```

Optional arguments:

- `--config`: path to `config.yaml` (default `config.yaml`).
- `--format`: `pdf` or `pptx`.
- `--max-slides`: limit the number of generated slides per video.
- `--lang`: override OCR/ASR language (e.g. `ru+en`).
- `--model`: override the LM Studio model name defined in config.

Outputs are stored under `reports/` and JSON logs under `logs/`.

## Configuration

Adjust thresholds, paths, and LLM prompts in `config.yaml`. The LM Studio server base URL can also be set through the `OPENAI_API_BASE` environment variable.
