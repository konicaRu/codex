# Offline Meeting Minutes Generator

This project provides a Windows-friendly, fully offline tool that splits meeting videos into "slides", extracts screen text and speech, summarises each segment with a local LLM (via LM Studio), and exports the result into PDF or PPTX reports.

## Features

- Scene detection using HSV histograms and SSIM with best frame selection by Laplacian variance.
- OCR through Tesseract (rus+eng) and offline speech-to-text with `faster-whisper`.
- Summaries, topic clustering, and action items generated by a local LM Studio deployment.
- Automatic rendering into PDF (ReportLab) or PPTX (python-pptx) reports with an aggregate summary slide.
- Simple CLI that works offline on Windows 10/11 with Python 3.10+.
- Встроенный локальный веб-интерфейс для запуска из браузера.

## Installation

Install Python dependencies (offline wheels if required):

```bash
pip install -r requirements.txt
```

System prerequisites:

- `ffmpeg` available in `PATH`.
- Tesseract OCR with Russian and English language packs.
- LM Studio running locally (`http://localhost:1234/v1`).

## Пошаговый запуск (GUI)

Ниже — пошаговая инструкция в формате «сделал → увидел», включая варианты развития событий.

1. **Подготовка проекта**
   - *Сделал:* скачал репозиторий (ZIP или `git clone`) и распаковал его, например в `C:\Projects\video-minutes`.
   - *Увидел:* в папке лежат `README.md`, `requirements.txt`, папка `app/` и `config.yaml`.
   - *Если иначе:* если файлов нет, проверьте, что архив распакован полностью и без вложенной дополнительной папки.

2. **Создание виртуального окружения**
   - *Сделал:* в PowerShell: 
     ```powershell
     cd C:\Projects\video-minutes
     python -m venv .venv
     .\.venv\Scripts\activate
     pip install -r requirements.txt
     ```
   - *Увидел:* после активации перед приглашением появится `(.venv)`, а `pip` сообщает об успешной установке пакетов.
   - *Если иначе:* если `pip` жалуется на отсутствие колёс, заранее скачайте колёса зависимостей на другой машине и укажите путь к ним (`pip install --no-index --find-links <папка>`).

3. **Проверка системных компонентов**
   - *Сделал:* удостоверился, что `ffmpeg` доступен в `PATH`, Tesseract установлен с языками `rus` и `eng`, LM Studio запущен и модель выбрана.
   - *Увидел:* при запуске `ffmpeg -version` или `tesseract --version` в PowerShell выводятся версии; в LM Studio сервер показывает статус «Running» на `http://localhost:1234/v1`.
   - *Если иначе:* если `ffmpeg` или `tesseract` не находятся, добавьте их папки в переменную `PATH` или отредактируйте соответствующие поля в `config.yaml`.

4. **Старт GUI-сервера**
   - *Сделал:* запустил сервер: 
     ```powershell
     python -m app.gui_server
     ```
   - *Увидел:* в консоли сообщение ` * Running on http://127.0.0.1:5000` и логи о проверке окружения.
   - *Если иначе:* при ошибке «порт занят» добавьте `--port 5050`; если ругается на конфиг, укажите путь через `--config C:\...\config.yaml`.

5. **Открытие HTML-интерфейса**
   - *Сделал:* открыл `app/gui/index.html` двойным щелчком или перетащил в браузер.
   - *Увидел:* страницу с тремя блоками: проверка окружения, форма загрузки и история задач.
   - *Если иначе:* если страница не отображает стили/скрипты, убедитесь, что браузер разрешает локальные файлы, либо откройте через `http://127.0.0.1:5000` напрямую.

6. **Проверка окружения в GUI**
   - *Сделал:* дождался автоматической проверки (или нажал «Обновить»).
   - *Увидел:* зелёные галочки напротив `FFmpeg`, `Tesseract`, `LM Studio` и выбранной модели.
   - *Если иначе:* появятся жёлтые/красные предупреждения с инструкциями: куда положить `ffmpeg`, как установить языковые пакеты Tesseract, как запустить LM Studio и выбрать модель. После исправления нажмите «Повторить проверку».

7. **Запуск обработки видео**
   - *Сделал:* выбрал файл `.mp4/.mkv/.mov`, указал формат (PDF или PPTX), задал опции (`--max-slides`, язык и т. п.) через дополнительные поля и нажал «Собрать отчёт».
   - *Увидел:* в блоке статуса появилась новая задача со статусами «Загрузка», затем «Обработка» с прогрессом.
   - *Если иначе:* если файл не принимается, проверьте расширение и размер; при ошибке «не хватает места» очистите `temp/` в корне проекта.

8. **Получение результата**
   - *Сделал:* дождался статуса «Готово» и кликнул по ссылке на PDF/PPTX или JSON-лог.
   - *Увидел:* открылся отчёт в папке `reports/` (название `report_<имя_файла>.pdf|pptx`) и лог в `logs/`.
   - *Если иначе:* статус «Ошибка» содержит текст проблемы (например, `faster-whisper` не нашёл модель). Исправьте по подсказке и перезапустите шаг 7.

9. **Повторный запуск**
   - *Сделал:* нажал «Очистить историю» или загрузил новое видео.
   - *Увидел:* предыдущие задачи скрыты, новые добавляются в очередь без перезапуска сервера.
   - *Если иначе:* при зависаниях перезапустите `python -m app.gui_server` и обновите страницу браузера.

10. **Завершение работы**
    - *Сделал:* остановил сервер комбинацией `Ctrl+C` в консоли.
    - *Увидел:* сообщение `Server stopped` и возврат к приглашению PowerShell.
    - *Если иначе:* если консоль «не отпускает», закройте окно PowerShell или завершите процесс через диспетчер задач.

## CLI Usage

```bash
python -m app.cli --input path/to/video_or_folder --format pdf --lang ru+en
```

Optional arguments:

- `--config`: path to `config.yaml` (default `config.yaml`).
- `--format`: `pdf` or `pptx`.
- `--max-slides`: limit the number of generated slides per video.
- `--lang`: override OCR/ASR language (e.g. `ru+en`).
- `--model`: override the LM Studio model name defined in config.

Outputs are stored under `reports/` and JSON logs under `logs/`.

## Configuration

Adjust thresholds, paths, and LLM prompts in `config.yaml`. The LM Studio server base URL can also be set through the `OPENAI_API_BASE` environment variable.
